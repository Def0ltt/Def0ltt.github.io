Privacy Policy for ESEA Checker

This extension interacts with the data displayed on the web page you are currently viewing and temporarily fetches information through the Faceit API to provide relevant data such as player nicknames and league divisions.

Data Usage: The extension does not store, collect, or share any personal data. The only data accessed is from publicly available sources on the Faceit website.

No Data Storage: All data fetched through the API is not stored or saved by the extension. It is only used temporarily to display the required information on the extension's pop-up.

API Interaction: The extension communicates with the Faceit API to retrieve league and player data for the purpose of displaying it to you on the extension interface.

By using this extension, you consent to the temporary access of the information on the web page to provide these features.
